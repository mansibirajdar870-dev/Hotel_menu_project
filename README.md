🍽️ Hotel Crazy Zone

About the Project

Hotel Crazy Zone is a beginner-level, menu-driven hotel ordering and billing system developed using the C programming language. It allows users to explore food categories, select menu items, enter quantities, and calculate the bill.

Technologies Used

- C Programming Language
- Standard Input/Output ("stdio.h")
- Switch statements
- Do-while loops
- User input using "scanf()"

Features

- Separate vegetarian and non-vegetarian menus
- Multiple food categories
- Food item selection
- Quantity input
- Bill calculation
- Console-based user interface

How to Run

1. Download or clone this repository.

2. Open the project folder in VS Code.

3. Compile the C program using GCC:
   
   "gcc hotel_menu.c -o hotel_menu"

4. Run the program:
   
   Windows:
   ".\hotel_menu.exe"
   
   Linux/macOS:
   "./hotel_menu"
